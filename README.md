Website for the Mausehochzeit 2019, served at https://wischli.github.io/mausehochzeit/. Built with [Vite](https://vite.dev) and React.

## Scripts

* `npm start`: dev server on http://localhost:5173/mausehochzeit/
* `npm test`: runs the tests with Vitest
* `npm run build`: builds the site into `build/`
* `npm run preview`: serves the built site locally
* `npm run deploy`: builds and publishes `build/` to the `gh-pages` branch, which GitHub Pages serves
